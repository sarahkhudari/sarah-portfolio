Recommended size:
  - Card / hero (16:9 or 16:10): 1600x1000
  - Mobile screenshots: any portrait size — they’ll be letterboxed
    over the soft pink gradient automatically.
JPG or PNG both work.

If an image is missing, the spot stays as a soft pink gradient
placeholder, so the site still looks polished while you gather
your screenshots.
